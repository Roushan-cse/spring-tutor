# Spring Tutor

An AI-powered Spring Boot Tutor built using:

- FastAPI
- LangChain
- Pinecone
- HuggingFace Embeddings
- RAG Architecture

## Features

- Ask questions from Spring Boot course PDFs
- Retrieval Augmented Generation
- Semantic Search
- Context-aware Answers

## Tech Stack

- Python
- FastAPI
- Pinecone
- LangChain
- HuggingFace
